# Version: *2.0.0* - Date: *2025-09-27*

---

### 🚀 **Overview**
Version 2.0.0 brings significant improvements including database migration changes (from `int` IDs to `Guid`), project structure refactoring, new configuration options, and several bug fixes.  

### ✨ **Added**  
* New property: `DisableDatabaseMigrationsOnStartup` added to `ProviderConfiguration`.  

### 🔄 **Changed**  
* Database IDs migrated from `int` ➝ `Guid` (⚠️ **breaking change** – requires a new database).  
* Renamed project files, routes, and file names for consistency.  
* Refactored codebase for maintainability and performance.  

### 🐛 **Fixed**  
* Fixed ordering and deleting settings not working properly.  
* Fixed relative URIs in REST endpoints.  
* Fixed various UI bugs.  
* Cache cleanup issues in notifications resolved.
